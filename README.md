# Dependency Injection
This repository contains sample projects to learn dependency injection in Android from scratch.

I will add here two main DI frameworks (`Dagger 2` and `Dagger-Hilt`) as I learn them myself.

This repository is structured as follows:
1. There will be 2 main types of branches – `dagger2` and `hilt`
2. Every other branch is called as `dagger2-*` or `hilt-*`
3. The purpose of the other branches is to make the code easier to read and also to use them as checkpoints (in case the commit list gets overloaded)
